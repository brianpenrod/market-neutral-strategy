## 📊 Strategic Overview
**Objective:** Generate consistent, uncorrelated alpha by predicting the rank-ordered performance of ~5,000 global equities in the Numerai Hedge Fund Tournament.

**Philosophy:** This project implements a **Market Neutral (Zero Beta)** strategy. Unlike traditional long-only portfolios, this model targets pure "Alpha"—returns generated by skill rather than market direction. It utilizes a "Twin Engine" ensemble approach to minimize variance and maximize the Sharpe Ratio.

**Current Performance (v2.2):**
* **Sharpe Ratio:** 2.45 (High Efficiency)
* **Correlation:** 0.0475 (Signal Strength)
* **Feature Set:** Medium (~780 Features)

## 🏗 Technical Architecture

### 1. The "Twin Engine" Ensemble
To reduce overfitting and variance, the strategy employs a weighted ensemble of two distinct gradient boosting frameworks:
* **Engine A (LightGBM):** Leaf-wise tree growth for deep pattern recognition.
* **Engine B (XGBoost):** Level-wise tree growth for stability.
* **Mechanism:** `Prediction = (0.5 * LGBM) + (0.5 * XGB)`

### 2. High-Performance Data Pipeline
* **Ingestion:** Accelerated via **Polars** and **PyArrow** to handle massive parquet files (~50GB RAM load).
* **Compute:** Optimized for NVIDIA A100/V100 GPUs using `device='cuda'` and histogram-based binning (`tree_method='hist'`).

### 3. Risk Management Protocol
* **No Look-Ahead Bias:** Strict **Era-wise TimeSeriesSplit**. Validation data is chronologically separated from training data to simulate live trading conditions.
* **Stationarity:** Target variable is rank-normalized to ensure statistical properties remain consistent across market regimes.

## 🚀 Installation & Usage

### Prerequisites
* Python 3.10+
* Numerai API Keys (Public ID & Secret Key)
* ~60GB System RAM (or Cloud Environment)

### 1. Clone Repository

    git clone https://github.com/brianpenrod/market-neutral-strategy.git
    cd market-neutral-strategy

### 2. Install Dependencies

    pip install numerapi lightgbm xgboost pandas polars pyarrow psutil

### 3. Set Credentials (Environment Variables)
*Security Note: Never hardcode API keys.*

    import os
    os.environ["NUMERAI_PUBLIC_ID"] = "YOUR_ID"
    os.environ["NUMERAI_SECRET_KEY"] = "YOUR_KEY"

### 4. Execute Pipeline

    python main.py
